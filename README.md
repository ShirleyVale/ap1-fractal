# AP1 · 交互式 2D 分形

基于原生 WebGL 2.0 的 Sierpinski 垫片交互实验。项目使用 `Float32Array` 组织顶点数据，并通过 VBO 的 `gl.bufferData` 上传到 GPU。

## 运行

公网运行地址：[https://shirleyvale.github.io/ap1-fractal/](https://shirleyvale.github.io/ap1-fractal/)

直接双击 `dist/index.html` 也可运行。入口已使用非模块化浏览器脚本，避免 Chrome/Edge 对 `file://` 下 ES Module 导入的拦截。也可在项目根目录运行任意静态服务器，例如：

```bash
npx serve dist
```

然后打开命令行显示的本地地址。项目没有构建步骤。

## 两种生成算法

### 1. 混沌游戏

从一个随机初始点 `p` 开始，每次随机选择三角形的一个顶点 `v`，执行 `p = (p + v) / 2`，再把 `p` 作为一个顶点。迭代足够多次后，点集会收敛到 Sierpinski 垫片。本项目可生成 5,000 至 60,000 个点，并用 `gl.POINTS` 绘制；五边形和六边形为加分扩展。

### 2. 递归细分

对一个三角形取三条边的中点，把它分成四个小三角形，只保留三个角上的三角形，继续递归。深度为 `d` 时保留 `3^d` 个三角形。程序在 CPU 端递归构造顶点数组，再将三角形数据上传到 VBO。点云、线框、实体三种模式共用该组三角形数据。

## 交互说明

- 方法切换：面板中选择“混沌游戏”或“递归细分”。
- 参数：混沌游戏可调点数；递归细分可调深度 0–6；还可调点大小、配色、图形类型。
- 图形类型：三角垫片可使用两种算法；选择五边形或六边形时，程序自动切换到混沌游戏点云模式。多边形模式会避开上一次的相邻顶点，以呈现不同的 n 边形垫片。
- 渲染模式：点击面板的点云、线框、实体按钮，或按 `1`、`2`、`3`。线框和实体模式会自动选择递归细分算法，因为混沌游戏按任务要求以点云绘制。
- 鼠标：左键拖动画布可平移；滚轮可缩放；“重置视图”恢复初始位置。
- 动画：按空格或点击“暂停生长”暂停或继续逐点生长。
